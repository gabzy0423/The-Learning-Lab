# Add a FAQ section before the closing CTA

The homepage will add a compact FAQ section between the About The Learning Lab preview and the final Start a Conversation CTA. It will use a split desktop layout with introductory copy on the left and an Accordion on the right; mobile will stack the two columns.

The section will begin with four proposed questions and answers derived only from approved homepage language about learning programs, Digital Solutions, The Learning Lab approach, and the consultation path. The copy will remain clearly proposed until FAQ answers are validated.

The Accordion will have all items closed by default and allow only one open item at a time. Existing keyboard behavior, focus visibility, and reduced-motion handling will be preserved.
