# Keep the Hero as the first-viewport boundary

The homepage Hero will be the primary first impression: on `lg` screens it fills the available viewport below the navbar, with vertically centered copy, CTAs, and the existing Hero Image. The organization-logo marquee is a separate quiet Trust Strip below the Hero, with no negative overlap and the same horizontal alignment as the navbar/Hero container; mobile and tablet remain content-driven so the layout does not become cramped.

The Hero will use balanced emphasis: the image may be slightly larger than the copy, while the desktop headline targets approximately 64px and the supporting paragraph, CTAs, proof points, and image callouts scale with it. This keeps the first impression strong without allowing one element to dominate.

The Trust Strip will use a white floating card with rounded corners, a subtle border, and a restrained shadow. It will overlap the top of the Signature Learning Portfolio by 24px on desktop while remaining below the initial Hero-only viewport; mobile and tablet will render it inline to protect the logo layout and reading flow.
