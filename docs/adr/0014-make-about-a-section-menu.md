# Make About a section menu

The primary About navigation item will become a dropdown-only control, matching the Programs interaction model. It will expose `About The Learning Lab`, linking to the existing `/about` page, and `Meet The Team`, linking to a `#meet-the-team` section on that same page. The team section will use clearly marked proposed structure and copy until approved names, photos, and bios are available. The submenu will be available in both desktop and mobile navigation.

**Status:** accepted
