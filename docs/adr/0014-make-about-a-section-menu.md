# Make About a section menu

The primary About navigation item became a dropdown-only control, matching the Programs interaction model. It exposed `About The Learning Lab`, linking to `/about`, and `Meet The Team`, linking to a `#meet-the-team` section on that same page. The submenu was available in both desktop and mobile navigation.
