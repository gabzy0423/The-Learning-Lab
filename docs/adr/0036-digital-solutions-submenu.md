# Make Digital Solutions a section menu

The primary Digital Solutions navigation item will become a dropdown-only control, matching the About and Learning Programs interaction model. It will expose two child destinations:

- `Custom Human Resource Information System (HRIS)` → `/solutions/hris`
- `Competency Platform` → `/solutions/competency-platform`

The existing `/solutions` route remains available as a fallback, but it is not the direct target of the top-level navigation control. Until the solution content is approved, both child routes will use clearly marked proposed placeholder pages rather than invented claims.

On desktop (`lg` and above), the menu will use the existing hover-assisted behavior with click and keyboard support. On mobile and tablet, it will remain click-controlled inside the navigation drawer.

**Status:** accepted
