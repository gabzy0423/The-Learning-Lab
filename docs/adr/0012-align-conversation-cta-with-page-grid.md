# Align the conversation CTA with the page grid

The “Start a conversation” section will use the same `80rem` horizontal container, desktop edge alignment, responsive heading scale, natural text wrapping, and CTA treatment as the other homepage sections. Its conversion layout remains unique: conversation copy on the left and a “Choose your next step” action panel on the right.

The section will present that conversion layout inside one centered Charcoal container with a compact vertical rhythm. The outer section remains White for breathing room; the container uses White copy, muted supporting text, Mint Green emphasis, and stacked actions on mobile.
