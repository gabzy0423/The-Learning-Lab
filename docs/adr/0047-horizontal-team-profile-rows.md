# Use horizontal rows for the Meet The Team people section

The `Our people` section will replace the current card grid with one full-width horizontal row per team slot. Each row will organize the member label, portrait or approved placeholder, identity, short description, and non-clickable profile status; approved profiles will show only supplied information, while the remaining slots stay pending without invented names, roles, locations, skills, biographies, or routes. Desktop uses the horizontal composition and mobile stacks the same content order without horizontal scrolling.

**Status:** accepted
