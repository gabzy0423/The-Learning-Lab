# Use sequential full-row assets for the Trust Strip

The Trust Strip will use the four prepared marquee assets in `public/assets/marquees/1.png` through `4.png` as sequential full-row images. The loop order is `1 → 2 → 3 → 4 → 1`, the rows remain uncropped with `object-contain` behavior, and the previous `approved-organizations.png` sprite is no longer used for the marquee.
