# Redesign Signature Portfolio program cards

The five Signature Learning Portfolio program cards will use a readable vertical content layout: a prominent standalone icon, program name, expanded two-sentence proposed description, approved program image, and a persistent `Explore Program` action linking to the current program route. Cards will use generous internal spacing, a consistent 160–180px image area, and a subtle static charcoal overlay at approximately 12–15% opacity on the image only. Each card will crossfade from its base image to the matching `alt_*.png` image on hover and keyboard focus, while touch/mobile keeps the base image visible; both image states retain the overlay and zoom treatment. The full-card hover overlay remains removed, and the blank sixth placeholder remains unchanged.

**Status:** accepted
