# Redesign Signature Portfolio program cards

The five Signature Learning Portfolio program cards will use a readable vertical content layout: a prominent standalone icon, program name, expanded two-sentence proposed description, approved program image, and a persistent `Explore Program` action linking to the current program route. Cards will use generous internal spacing, a consistent 160–180px image area, and a subtle static charcoal overlay at approximately 12–15% opacity on the image only; the existing image hover zoom remains, while the full-card hover overlay is removed. Existing program meaning, icons, images, routes, and the blank sixth placeholder remain unchanged.

**Status:** accepted
