# Match team cards to the program card treatment

The Meet The Team `Our people` grid will reuse the Personal Development card hierarchy without inventing team data. Each card will use an outer white card shell, a numbered label, an inner square image frame, `object-contain` image behavior so portraits remain fully visible, and a neutral `Profile pending` line until approved names, roles, and biographies are available.

Cards will use the same subtle hover treatment as the program cards: a 500ms transition, a small upward lift, and a soft border/shadow response. Placeholder cards remain non-clickable until approved profile destinations exist.
