# Share the program category banner pattern

Personal Development and Managing Work will use the same category-banner structure: a left-aligned eyebrow, category title, supporting description, consistent typography, spacing, dark image overlay, and desktop alignment rail. Each category keeps its own approved copy. A `Start your journey` CTA is added only when the page has a valid in-page section target; Managing Work will not show a scroll CTA until its program content section exists.
