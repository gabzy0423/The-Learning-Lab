# Brand and Media Asset Inventory

Working plan for incorporating organization-provided materials into the semi-production website. Assets remain pending review until their file quality, usage rights, approval status, and intended placement are confirmed.

## Asset groups

| Asset group | Planned website use | Status | Required checks |
|---|---|---|---|
| Logo | Header, footer, favicon/brand moments where appropriate | Pending review | Official file, light/dark variants, clear-space rules, usage rights |
| Promotional reels | Hero or selected marketing sections | Pending review | Web format, duration, captions/transcript, mobile behavior, permission |
| Short promotional videos | Promotional or solutions sections | Pending review | Web format, poster frame, captions, loading impact, permission |
| Brochures and catalogues | Supporting resources or download links if approved | Pending review | Final PDF, public distribution permission, accessible text, current version |
| Course images | Program category and validated course pages | Pending review | Course mapping, resolution, crop variants, alt text, permission |

## Integration rules

- Use organization-provided assets before generic or unapproved stock assets.
- Do not publish an asset until its source, approval status, and usage rights are known.
- Map course images only to validated courses or clearly approved category content.
- Use video only when it strengthens the message and does not harm readability, performance, or accessibility.
- Provide a non-video fallback, captions/transcript where applicable, and meaningful poster frames.
- Treat brochures and catalogues as supporting content, not a replacement for readable website content.
- Keep asset selection purposeful; avoid adding media merely because it is available.
- Competency Platform visuals, if used, must remain illustrative concept media and must not expose internal operational data.

## Inputs needed

- Asset folder or upload location.
- File names and any intended page/course mapping.
- Brand guide and logo usage rules.
- Confirmation of ownership or permission to publish each asset.
- Latest/final versions of brochures and catalogues.
