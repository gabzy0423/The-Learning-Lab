# The Learning Lab — Brand Color System

Approved working color direction for the semi-production corporate website. These values are the current project decision and may be refined only when the official brand guide provides authoritative values.

## Palette

| Token | Hex | Role |
|---|---|---|
| Deep Purple | `#281052` | Primary brand color, headings, navigation, primary CTA backgrounds, dark sections |
| Mint | `#55DFBE` | Learning/progress accent, soft highlights, secondary surfaces |
| Orange | `#FFBD59` | Warm supporting accent, badges, selected highlights |
| Coral | `#FF6875` | Human energy, attention highlights, secondary CTA accents |
| Off-White | `#F8F6FC` | Main page background and soft section surfaces |

## Usage rules

- Deep Purple is the visual anchor and should carry the strongest brand presence.
- Off-White is the default page background to keep the interface calm and readable.
- Mint supports learning, growth, and positive states; use it as an accent or surface, not as long-form body text.
- Orange and Coral are controlled accents; do not use both at equal strength in the same section.
- Use Deep Purple text on Mint, Orange, Coral, and Off-White surfaces unless contrast testing proves another pairing safe.
- Use white text primarily on Deep Purple backgrounds.
- Avoid default gradients, rainbow palettes, neon treatments, and large competing accent blocks.
- Color must not be the only signal for status, category, or interaction state.

## Visual mood

Warm, confident, human, and professional. The palette should feel energetic enough for learning without becoming playful or informal for HR/L&D decision-makers.
